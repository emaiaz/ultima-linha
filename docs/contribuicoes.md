## Como finalizar este registro

Antes de entregar, conversem rapidamente e preencham a participação de cada pessoa com exemplos concretos. Se uma tarefa foi dividida, indiquem isso. Se alguém ajudou em várias partes, registrem mais de uma contribuição. Confiram também os nomes completos e as datas. Este histórico é um registro do trabalho do grupo, não uma divisão presumida de responsabilidades.
